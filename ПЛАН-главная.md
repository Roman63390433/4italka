## Экран «Главная»
1. Поиск «Книга, автор или жанр» — по своей полке + каталогу классики + FantLab вживую (`/search-works?q=`).
2. Книга дня — из каталога классики, по дате.
3. **Современное** — вкладки по жанрам (Фэнтези, Фантастика, Мистика и ужасы, Проза, …) из новинок FantLab.
4. Подборки классики, авторы (кружки с буквой → книги автора).
5. Новости — заголовок, источник, дата; тап — статья в браузере.

Карточка книги: обложка, описание, жанры, год/издательство; кнопки **«Хочу прочитать»** (книга на полке без файла со статусом «хочу»; добавленный позже файл привязывается к ней по названию+автору) и **«Где взять»** (поиск на Литресе). У классики — **«Добавить на полку»** (скачать с Викитеки).

## Данные
- FantLab: `/pubnews` — новинки (30 шт., поля name, autors, date, publisher, description, edition_id, pic_orig, series); `/edition/{id}` → произведение; `/work/{id}/extended` → `work_description`, `classificatory.genre_group` (жанры голосованием), `image`. Поиск: `/search-works?q=`. Обложки: `https://fantlab.ru` + путь картинки. В текстах убирать разметку `[autor=..]..[/autor]`, `[pub=..]`, `[work=..]`.
- Новости: RSS «Год литературы» `https://godliteratury.ru/rss` (работает, но CORS нет → только через робота). Ещё источники подобрать и проверить.
- Викитека: `w/api.php?action=parse&page=<страница>&prop=text|links&format=json&origin=*&formatversion=2`. Длинные книги — подстраницы-главы.

## Части (логика отдельно от интерфейса)
- `tools/build-home.mjs` + `.github/workflows/home.yml` — **робот GitHub раз в день**: новинки FantLab с жанрами + RSS новостей → `data/home.json` (коммитит в main). Без секретов.
- `tools/build-catalog.mjs` — один раз собирает `data/catalog.json` (100–150 книг русской классики, только реально существующие страницы Викитеки: название, автор, год, жанр, страница, описание если есть).
- `js/catalog.js` — каталог классики, поиск, книга дня, подборки.
- `js/wikisource.js` — скачать с Викитеки (с главами) → собрать fb2 → обычный путь `storage.addBook` (через существующий разборщик fb2 и `sanitize.js`).
- `js/fantlab.js` — живой поиск FantLab, чистка разметки.
- `js/home-data.js` — чтение `data/home.json` (без интернета — последний сохранённый).
- `js/home.js` — интерфейс главной и карточки книги (`sheet.js` для панелей, без alert/confirm).
- Книга без файла («хочу»): поле `wish: true` в `books`, без записи в `files`; полка показывает её с пометкой «нет файла»; при добавлении файла — привязка. Проверить, нужна ли новая версия IndexedDB (по правилам — только через `oldVersion`).
- Новые файлы — в `FILES` в `sw.js`, поднять `VERSION`. `data/*.json` — сеть сначала, кеш как запасной.

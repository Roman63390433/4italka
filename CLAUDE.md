# Читалка — приложение для чтения книг на телефоне

Учебный проект пользователя (программирование с нуля): объяснять простыми словами, по ходу работы.

## Что это
PWA (сайт, который ставится на главный экран Android) для чтения своих книг fb2 / fb2.zip / epub. Без сервера и без чужих библиотек: книги в IndexedDB телефона, настройки и место чтения в localStorage.
Устройство, файлы, путь данных — **[ARCHITECTURE.md](ARCHITECTURE.md)** (читать перед правками кода).

## Как запускать и проверять
- На компьютере: конфигурация `chitalka` в `C:\Клод\Свои проекты\.claude\launch.json` (python http.server, порт 5521). С `file://` не работает (модули и Service Worker).
- Тестовые книги: `node tools/make-test-books.mjs` → `test/`. Добавлять через «+» или в консоли через DataTransfer на `#fileInput`.
- Новые файлы приложения вписывать в список `FILES` в `sw.js` и увеличивать `VERSION`.

## Выкладка
Коммит и `git push` в main → GitHub Pages сам обновит сайт за 1–2 минуты. `макеты/` в репозиторий не идут (.gitignore). В репозитории лежат и служебные `test/`, `tools/`, `*.md` — секретов в них нет.

## Дизайн
Три стиля на выбор пользователя (`data-style` на `<html>`): **Спокойный** (`calm`), **Винтаж** (`vintage`, «альбом»), **Библиотека** (`autumn`). Цвет страницы при чтении отдельно: По стилю / Белый / Сепия / Серый / Тёмный. Цвета и шрифты — токены в начале `css/style.css`.
Завитки в стилях 2–3 генерирует `tools/ornaments.mjs` (правки там, потом `node tools/ornaments.mjs`). Картинки — только без людей. Шрифты — бесплатные OFL с кириллицей (Google Fonts, кешируются для офлайна).

## Правила
- Логика (`storage`, `parsers`, `zip`, `sanitize`, `anchor`, `view`, `paginator`, `scroller`, `settings`) не трогает кнопки; интерфейс — в `app`, `shelf`, `reader-ui`, `look`, `sheet`.
- HTML из книги — только через `sanitize.js` (или собран вручную в `fb2.js`).
- Без alert/confirm — только `ask()` и `toast()` из `sheet.js`.
- Место в книге — только якорем `{ ch, off }` (номер буквы), не номером страницы.
- Значок — `node tools/make-icons.mjs`.
- История правок — `ЖУРНАЛ.md`.

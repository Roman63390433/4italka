# Архитектура «Читалки»

Читалка — PWA: обычный сайт из HTML, CSS и JavaScript, который Chrome на Android ставит на главный экран. Сервера нет, всё хранится в телефоне. Сборки нет: файлы открываются браузером как есть. Чужих библиотек тоже нет — даже zip распаковывается встроенными средствами браузера.

## Части и связи

```
 Экран (index.html + css/style.css)
   │  нажатия
 ┌─▼──────────── ИНТЕРФЕЙС ─────────────┐
 │ app.js        — запуск, нижнее меню, экран «Ещё» (стиль, место в памяти)
 │ shelf.js      — полка: список, добавление, удаление, поиск, чипы статусов, долгое нажатие → статус
 │ series-ui.js  — карточки серий и окно правки серии
 │ covers.js     — обложки и «долгое нажатие» (общие для полки и серий)
 │ reader-ui.js  — экран чтения: касания, меню, оглавление, сноски
 │ look.js       — панель «Aa»: применяет настройки (общие или книги) и рисует переключатели
 │ marks-ui.js   — закладки и заметки: кнопка, риски, шторка, полоска цветов при выделении, окно заметки
 │ sheet.js      — панели снизу, вопросы, подсказки (вместо alert/confirm) и кнопка «назад» Android
 └─┬───────────────────────────────────┘
   │ вызывает
 ┌─▼──────────── ЛОГИКА (без кнопок) ───┐
 │ parsers/index.js — определяет формат и зовёт нужный разборщик
 │ parsers/fb2.js   — fb2 → главы, обложка, сноски
 │ parsers/epub.js  — epub → главы, обложка
 │ zip.js           — распаковка zip (epub и fb2.zip)
 │ sanitize.js      — чистит HTML книги: пропускает только безопасные теги
 │ anchor.js        — «якорь»: место в главе = номер буквы; первая видимая буква, текст отрывка, подсветка
 │ marks.js         — закладки и заметки: создание, поиск, группы по главам, текст для выгрузки
 │ status.js        — статусы книг и правило «открыли — читаю»
 │ series.js        — серии: группы, «прочитано N из M», следующая, пропущенные номера
 │ view.js          — общее у двух режимов чтения (проценты, ползунок)
 │ paginator.js     — режим «страницы»: глава в CSS-колонки, листание
 │ scroller.js      — режим «лента»: прокрутка, главы подгружаются сверху и снизу
 │ settings.js      — настройки по умолчанию, проверка, настройки одной книги
 └─┬───────────────────────────────────┘
   │ читает и пишет
 ┌─▼──────────── ХРАНИЛИЩЕ ─────────────┐
 │ storage.js: IndexedDB «chitalka» (версия 2) — books (название, автор, обложка, размер),
 │             files (сам файл книги), marks (закладки и заметки); localStorage — настройки и место чтения
 └──────────────────────────────────────┘
 sw.js + manifest.json — значок на экране и работа без интернета
```

Правило: файлы логики ничего не знают про кнопки и экраны. Интерфейс вызывает логику, а не наоборот.

## Путь данных

1. **Добавление.** «+» → системный выбор файла → `shelf.js` → `parsers` достаёт название, автора, обложку и объём текста → `storage.addBook` кладёт карточку в `books`, а файл в `files` → полка перерисовывается.
2. **Открытие.** Нажатие на книгу → `storage.getFile` → `parsers` строит главы (HTML уже очищен) → `paginator` показывает нужную главу и страницу из сохранённой позиции.
3. **Листание / прокрутка.** Касание, свайп или прокрутка → режим (`paginator` или `scroller`) находит первую видимую букву (`anchor.js`) → позиция `{глава, номер буквы}` пишется в localStorage. Буква, а не номер страницы, — чтобы после смены шрифта, полей или режима открыть ту же фразу.
4. **Настройки.** Панель «Aa» → `settings.save` (или `saveBook`, если включено «Только для этой книги») → переменные CSS меняются → режим заново раскладывает текст и возвращается к той же букве. Смена режима: `reader-ui.switchMode` берёт якорь у старого режима и отдаёт новому.

5. **Закладка.** Значок в верхнем меню → режим отдаёт буквы, видные на экране (`shownRange`) → если закладки там нет — `marks.makeBookmark` → IndexedDB `marks`; если есть — снимается (с кнопкой «Вернуть»). Значок и ленточка в углу горят, когда на экране есть закладка; риски на ползунке — по доле книги `frac`.
6. **Заметка.** Выделение текста → `selectionchange` → номера букв начала и конца (`TextIndex.offsetOf`) → полоска цветов или «Заметка» → `marks.makeNote` → IndexedDB → главу на экране «переподсвечивают»: снимают все `<mark>`, обёртывают заново и пересчитывают буквы. Подсветка не меняет текст, поэтому номера букв остаются прежними. Подсветка ставится до подсчёта букв: режим чтения вызывает `decorate(элемент главы, глава)` сразу после вставки текста.
7. **Выгрузка.** «Сохранить заметки в файл» → `marks.exportText` → файл .txt → «Поделиться» Android (сохранить, отправить); если браузер так не умеет — обычное скачивание в «Загрузки».

8. **Статус.** Новая книга — «хочу прочитать». Открытие (`reader-ui`) → `statusOnOpen` → «читаю». Долгое нажатие на книгу или «⋮ → Статус» → выбор → `updateBook`. Дочитали до 100% → вопрос «Отметить прочитанной?». У старых книг без статуса он выводится из прогресса (`statusOf`).
9. **Серии.** Разборщик достаёт серию из файла (fb2 `<sequence name number>`, epub `calibre:series` / `belongs-to-collection`) → поля книги `series`, `seriesNo`. Книги, добавленные раньше, один раз перечитываются в фоне (флаг `scanned`). Полка → `groupSeries` → карточки. «Всего в серии» задаётся вручную (иначе — по самому большому номеру на полке).

## Как считаются страницы

**Страницы.** Глава выводится в CSS-колонки шириной в экран. Одна колонка — одна страница, листание сдвигает текст на ширину экрана. Страницы в текущей главе считаются точно. Общее число («18 из 662») оценивается по числу букв: буквы всей книги делятся на число букв на одной странице текущей главы.

**Лента.** Каждая глава — `<section data-ch>`; на экране не больше 4 глав. Когда снизу остаётся меньше полутора экранов — дописывается следующая глава, у верха — предыдущая (прокрутка сдвигается так, чтобы текст не прыгнул).

**Якорь.** `TextIndex` (anchor.js) обходит кусочки текста главы и считает буквы. Первая видимая буква ищется двоичным поиском («до экрана или нет»), поэтому быстро даже на длинной главе.

## Обновление приложения

`sw.js` берёт файлы приложения из сети с `cache: "no-cache"` (всегда сверяется с сервером), а при установке — мимо кеша браузера. Иначе после выкладки телефон мог смешать новую страницу со старыми скриптами.

## Системный свайп снизу

Полностью его отменить нельзя. Что сделано: страница не тянется и не обновляется (`overscroll-behavior: none`, у ленты — `contain`); нижние 56 px экрана не листают; кнопки меню подняты над краем; при чтении включается полный экран (Fullscreen API, выключается на «Ещё»); меню открывается и свайпом вверх из середины экрана.

## Формат хранения

- `books`: `{ id, title, author, format, size, chars, cover: Blob|null, added, opened }`
- `files`: `{ id, blob }`
- `books` (дополнительно с этапа 2В): `status`, `statusAt`, `series`, `seriesNo`, `scanned` (1 — серия из файла уже искалась).
- localStorage `chitalka.series`: `{ "название серии в нижнем регистре": { total } }` — «всего книг», если задано вручную; `chitalka.shelfFilter` — выбранный чип полки.
- `marks`: `{ id, bookId, type: "bookmark"|"note", ch, start, end, quote, note, color, frac, chapterTitle, created }`, индекс `bookId`. Удаляются вместе с книгой.
- localStorage `chitalka.settings`: `{ style, page, font, size, lh, margin, align, mode, dim, fullscreen }`
- localStorage `chitalka.look.<id>`: настройки одной книги — только `{ font, size, lh, margin, align }`, если включено «Только для этой книги»
- localStorage `chitalka.pos.<id>`: `{ ch, off, percent, at }` (старые записи с `frac` вместо `off` тоже понимаются)

## Безопасность

Книга — чужой файл, в нём может быть вредный код. `sanitize.js` пересобирает текст из короткого списка тегов (абзацы, заголовки, курсив, картинки, таблицы…) без атрибутов. Скрипты, стили и ссылки наружу отбрасываются, а картинки берутся только из самой книги.
